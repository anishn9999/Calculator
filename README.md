# 🧮 Modern Calculator

A simple, responsive, and user-friendly **Calculator Web Application** built using **HTML, CSS, and JavaScript**.

The calculator performs basic mathematical operations such as addition, subtraction, multiplication, and division with a clean and responsive interface.

## 🌐 Deploy on Vercel

This project can be deployed easily on **Vercel** by connecting the GitHub repository.

### Steps:

1. Push the project to GitHub.
2. Open Vercel.
3. Click **New Project**.
4. Select your GitHub Calculator repository.
5. Click **Deploy**.
6. Vercel will generate a live website URL.

Vercel supports connecting a Git repository and automatically deploying new pushes, so future changes can be published automatically.

🔗 **Vercel:** https://vercel.com
